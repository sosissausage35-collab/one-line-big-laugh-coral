## The entry

`main.ts` (Node 22) writes a single original one-liner — at most 200
characters, no title, no setup, no explanation — to `/output/entry.txt`:

> I bought a houseplant to prove I could keep something alive. It filed for emancipation.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

The program is fully deterministic: every run writes the exact same line.
It uses no network, no secrets, and reads no files outside this repository.
